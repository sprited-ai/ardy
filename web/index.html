Free-text prompts need the 8B text encoder, which does not run in a browser; this build ships precomputed embeddings for the prompts above.

3.5

Steps and history length are baked into the exported graph. Kinematic constraints (keyframes, waypoints) are not available in the browser build yet.

Models are downloaded from Hugging Face (sprited/ardy-web-onnx) on first use and kept in the browser cache.

Pick a prompt in the Text tab and press Update Text Prompt; the new prompt takes effect from the next frame. Play streams motion: windows of 2 s are generated ahead on your GPU (WebGPU) and re-planned when playback approaches the end. Drag on the timeline to scrub. Left-drag rotates, right-drag pans, scroll zooms.

Everything runs client-side; the only network traffic is the one-time model download.
